# 🐂 牛馬薪水計 WorkHorse

即時顯示「今天已經賺了多少錢」(小數點後兩位),並換算成台灣日常消費品。純 HTML/CSS/JS、零依賴、資料只存在你的瀏覽器(localStorage)。桌面優先的小視窗網站(建議視窗約 400×560)。

## 在 Windows 執行
- **最簡單**:雙擊 `serve.bat`(需要 Python 或 Node.js 其中之一),會用 Edge 開成無網址列的小視窗。
- **不裝任何東西**:直接雙擊 `public/index.html`(可用,但無法「安裝成 App」與離線快取)。
- **安裝成 App**:用 Edge 開 `http://localhost:8123/` → `…` → 應用程式 →「將此網站安裝為應用程式」,之後可釘選到工作列。
- 手動:`cd public && python -m http.server 8123`

## 結構
```
public/                      網站根目錄
  index.html style.css
  js/core.js                 計算核心(時間戳為準,可在 Node 測試)
  js/defaults.js             預設設定與參考價格(都可在介面修改)
  js/i18n.js                 三語系文案(zh-TW / en / ja)
  js/prices.js               各國物價與法定薪資參考值(含來源與估算標記)
  js/stocks.js               股票代碼/簡稱查詢、收盤價解析、匯率換算
  js/boot.js                 最先載入,出錯時在畫面顯示原因與清除快取按鈕
  js/assets.js               依 asset-manifest 載入素材
  js/share.js js/app.js      成果卡 / 介面
  assets/workhorse/          素材包(保留 brand/ icons/ mascot/ backgrounds/)
    asset-manifest.json      素材路徑唯一來源
    asset-manifest.js        由 json 自動產生(讓 file:// 也能用)
tests/                       core / assets / i18n / prices / stocks 測試
worker/quote-proxy.js        選用的報價代理(Cloudflare Worker)
tools/fetch-market-data.mjs  每日抓股價/匯率(GitHub Actions 執行)
tools/build-manifest-js.js   修改 manifest.json 後執行,重新產生 .js
```
素材只用獨立 PNG;所有金額、時間、價格與中文都是 HTML 文字。

## 怎麼用
1. 右上角齒輪 → 設定**時薪**、**一週上哪幾天班**、**上下班時間**、**休息時段**(預設午休 12:00–13:00)。
2. 回到首頁就好了——**不用按任何打卡鈕**。網頁讀取這台裝置的當地時間,依班表算出現在賺多少、正在跳多少;休息時段自動暫停。
3. 臨時狀況用首頁兩顆小按鈕:**今天放假/請假**(或補班)、**加班 +30 分**。國定假日不會自動放假,當天按「今天放假」即可。
4. 上班日過完會自動寫進「流水帳」,「戰績」看月統計。

## 功能
- 依班表 + 當地時間自動計薪(時間戳為準,重新整理、隔天打開都不會漏算),支援跨午夜班
- 加班倍率(預設勞基法 1.34 / 1.67,依當天累計工時);每日目標與進度;預估月薪
- 流水帳:自動記錄、可補登/刪除/匯出 CSV;戰績:月薪資、工時、出勤、平均、加班、每日長條圖
- 薪資換算器:咖啡、便當(依縣市參考價)、手搖飲、火鍋、電影、交通、個人目標;價格全可編輯、新增、刪除;已解鎖 / 差額 / 還需工作幾分鐘(排除休息、套用加班倍率)
- 繁體中文 / English / 日本語(右上角切換,文案走輕鬆幽默路線)
- 成果卡 PNG(不含時薪與公司名稱)、老闆鍵(按 `H` 模糊金額)、定時「今天賺了多少」提示、備份匯出/匯入

> 「薪資等值」只是累積工資的消費換算,不代表扣稅、扣除其他成本後的實際可支配金額。

## 這筆錢能買啥?(地區、精選、探索更多)
「買得起」頁可選地區:**台灣 / 日本 / 菲律賓**。每個國家**各自獨立**(各查各的價格,不用匯率硬轉別國商品),切換時自動換幣別(TWD / JPY / PHP)、(沒手動改過的)時薪與加班倍率,以及該國的清單。
- **精選(首次只顯示 4 張)**:當地代表性飲品、代表性餐點、一般 2D 成人電影票、旅行基金(目標,可改)。
  台灣:50嵐珍珠奶茶 NT$50、鬍鬚張滷肉飯 NT$39、電影 約 NT$340、日本旅行基金 約 NT$40,000 ｜
  日本:Seven Café R ¥140、吉野家牛丼並盛 ¥498、TOHO 一般 ¥2,000、京都・大阪旅行基金 約 ¥80,000 ｜
  菲律賓:Buko Juice 約 ₱50、Jollibee Chickenjoy 約 ₱106、SM 一般 2D 約 ₱350、Boracay 旅行基金 約 ₱20,000
- **個人目標**:快速建立手機 / 相機 / 筆電 / 日本旅行 / 鏡頭基金,或自訂;可設名稱、價格、**上傳圖片**(縮成小圖存在瀏覽器)、已存金額與「已達成」。
- **股票與 ETF(Investment Power)**:獨立區塊,顯示參考股價、理論等值股數、交易單位(台股 1 張 = 1,000 股、日股 1 單元 = 100 株、美股 1 股)與報價時間、來源。
- **探索更多**(預設收合):咖啡與飲料、美食與零食、娛樂、交通與旅行、3C 與電子產品、個人目標。交通、捷運、高鐵、手機、筆電等都在這裡,按「加入」才進你的清單。
- 卡片顯示:插畫、名稱、當地參考價、**薪資等值份數**(不是「已買了」)、下一份還差多少、依目前有效計薪速度還要工作多久,以及**參考價來源與資料日期**;自己改過價格會標示「自訂價格」。所有價格都可編輯。
- 價格資料與每項來源寫在 `public/js/prices.js`;**標「約」的是估算**(只找到舊資料或價格區間,菲律賓與旅行基金最多)。
- 尚未做:城市級價格篩選(沒查到可靠的城市別價格,避免亂標)。

## 股票換算(資料來源)
「買得起」→「＋ 股票」:輸入代碼或簡稱(例:`2330`、`台積電`、`環球晶`、`AAPL`、`輝達`、`7203`、`トヨタ`)。各國可選的市場:台灣=台股+美股、日本=日股+美股、菲律賓=美股(PSE 暫不支援)。
- **台股:臺灣證券交易所 OpenAPI(上市)+ 證券櫃檯買賣中心 OpenAPI(上櫃)**,官方資料,含全部個股與 ETF 的官方簡稱與收盤價。
- **美股/日股**:沒有免費的官方交易所 API,改用 Yahoo Finance 取得收盤價(Stooq 可用時會交叉核對)。涵蓋 **S&P 500 全部成分股**、常見 ETF(SPY、VOO、QQQ、SCHD…)、約 110 檔日股。
- **不在清單裡的代碼**(例如小型股、其他 ETF):把代碼加進 `tools/extra-symbols.txt`(一行一個,日股寫 `7203.T`),推送後下次部署就會納入。在那之前,卡片會提示你按「編輯」手動輸入價格。
- 這些資料由 GitHub Actions 在**每個交易日收盤後**抓取(`tools/fetch-market-data.mjs`),存成網站自己的 `data/market.json`;瀏覽器只讀同網域檔案,不需跨站請求(Safari 也不會擋)。
- 資料檔裡沒有的代碼,才會即時向 Yahoo 查詢,並標示「即時查詢(非官方)」;抓不到時可手動輸入價格。
- 卡片上會標出收盤日期與資料來源。股價僅供「要工作多久」的概略參考,不是投資建議。

## 疑難排解(Safari 打不開 / 空白)
- 每次部署都會在檔案網址加上版本號,避免瀏覽器拿到「新的 index.html + 舊的 JS」而當掉。
- 若仍有問題,畫面底部會出現錯誤訊息與「清除快取並重新載入」按鈕;請把訊息截圖回報。
- 手動清除:iPhone 設定 → Safari → 進階 → 網站資料 → 搜尋 `github.io` → 刪除;Mac Safari:設定 → 隱私權 → 管理網站資料。
