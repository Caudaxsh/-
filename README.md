# 🐂 牛馬薪水計

即時顯示「今天已經賺了多少錢」(小數點後兩位),並換算成台灣日常消費品。純前端、零依賴、資料只存在你的瀏覽器(localStorage)。

## 使用方式(Windows)

| 方式 | 做法 | 特色 |
|---|---|---|
| **A. 小視窗(最簡單)** | 雙擊 `start-mini.bat` | 用 Edge/Chrome「應用程式模式」開 380×640 視窗,無網址列 |
| **B. 安裝成 App** | 用 Edge/Chrome 開啟(需 http 網址,如 GitHub Pages)→ 選單 →「安裝此網站為應用程式」 | 有桌面圖示、可釘選工作列、可離線 |
| **C. 置頂浮窗** | 點右上角 ⧉ | Chrome/Edge 116+ 的 Document Picture-in-Picture,永遠在最上層 |

不建議自己做 Windows 原生小工具:Windows 11 小工具板需要 Store 打包與簽章,Electron 要自己維護打包;PWA + 浮窗已經夠用。

本機預覽:`python -m http.server 8000` 然後開 `http://localhost:8000`。

## 功能
- 時薪、上下班、多段休息(休息不計薪)、跨夜班
- 加班倍率(預設勞基法 1.34 / 1.67,可改;可選下班後繼續算加班)
- 即時金額、每分/每秒進帳、目前有效時薪與倍率、下班倒數、下次休息
- 定時「今天賺了多少」提醒(頁內提示,可選 Windows 通知)
- **薪資換算器**:咖啡、便當(依縣市參考價)、手搖飲、火鍋、娛樂、個人目標;價格全部可編輯/新增/刪除;已解鎖/差額/還需工作分鐘(依實際有效速度,排除休息、套用加班倍率);貨幣表可擴充(`js/defaults.js` 的 `CURRENCIES`)
- **成果卡**:PNG 下載/複製,不含時薪與公司名稱,可選擇隱藏金額
- 老闆鍵:按 `H` 或 👁 模糊所有金額

> 「薪資等值」只是累積工資的消費換算,不代表扣稅、扣除其他成本後的可支配金額。

## 開發
- `js/core.js`:純計算(可測)。`node tests/core.test.js`
- `js/defaults.js`:所有預設價格與設定(僅為初始參考值)
